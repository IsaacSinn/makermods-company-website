# OpenBooth X Launch Video Design

## Goal

Create a horizontal X launch video for OpenBooth that introduces OpenBooth as a robot skills library, then proves the idea with three hackathon-winning demo clips side by side, and closes on MakerMods branding.

## Format

- Resolution: 1920x1080.
- Frame rate: 30 fps.
- Audio: silent.
- Export: `assets/open-booth/openbooth-launch-x.mp4`.

## Sequence

1. Continuous title/data beat over the OpenBooth hero video, darkened in the style of the provided NVIDIA reference without top or bottom black bars.
   - Text: `OpenBooth`, `skills`, `for Robots`.
   - `skills` uses MakerMods orange.
   - The underlying hero video keeps playing while the overlay changes to `OpenBooth Data`.
   - Typography uses Chakra Petch, matching the site's display font.
2. Dataset overlay using the same uninterrupted OpenBooth hero video and subtle site grid overlay.
   - Reinforces OpenBooth as a dataset/catalog of reusable robot skills.
   - Shows only `152 datasets` and `40 task tags`.
3. Hackathon proof beat with the three vertical demo clips playing side by side.
   - Overlay: `Recreate winning hackathon demos` and `with OpenBooth`.
4. Final brand beat on black with the MakerMods wordmark and `www.makermods.ai/openbooth`.

## Assets

- `assets/open-booth/hero.mp4`
- `assets/open-booth/openbooth_demo_1_clip.mp4`
- `assets/open-booth/openbooth_demo_2_clip.mp4`
- `assets/open-booth/openbooth_demo_3_clip.mp4`
- `makermods-app/assets/logo-wordmark-white.png`
- Chakra Petch font files downloaded into `build/openbooth-launch/fonts/` by the render script when needed.

## Implementation

The video is generated by a repeatable Node script that shells out to FFmpeg. Intermediate clips and preview frames live under `build/openbooth-launch/`.
