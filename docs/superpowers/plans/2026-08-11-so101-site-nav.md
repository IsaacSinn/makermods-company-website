# SO-101 Site Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a working SO-101 product-page link to every primary site navbar.

**Architecture:** Each static HTML page owns a duplicated `.nav-links` block. A standalone Node verifier enumerates every navbar page, checks the context-appropriate SO-101 URL, and ensures only the product page marks the link current.

**Tech Stack:** Static HTML, Node.js verification, browser layout inspection.

## Global Constraints

- Work only in `feature/homepage-gif-banner`.
- Do not commit or push.
- Preserve all existing nav links and actions.
